# Vokabeltrainer Arabisch

Offline-Web-App (PWA) zum Lernen arabischer Vokabeln aus Quran, Medina-Büchern 1–3 und Fusha-Grundwortschatz.

- Karteikarten mit 5 Stufen, Prüfung mit Eintippen (Deutsch ↔ Arabisch), Plural-Training
- Eigene Karten, Karten bearbeiten, Statistik, Darkmode
- Lernstand wird nur lokal im Browser gespeichert

Daten: Morphologie aus dem Quranic Arabic Corpus, Übersetzung Bubenheim/Elyas, Schrift Amiri (OFL).
